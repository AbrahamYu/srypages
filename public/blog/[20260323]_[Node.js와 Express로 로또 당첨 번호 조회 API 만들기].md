# Node.js와 Express로 로또 당첨 번호 조회 API 만들기

많은 개발자가 프로그래밍 학습의 재미있는 목표로 '로또 번호 관련 프로그램'을 한 번쯤 생각해봅니다. 오늘은 Node.js와 Express를 사용하여 특정 회차의 로또 당첨 번호를 알려주는 간단하고 실용적인 API를 만들어 보겠습니다. 이 과정을 통해 Express의 기본 사용법과 외부 API 데이터 연동 방법을 쉽게 익힐 수 있습니다.

## 왜 직접 API를 만드나요?

물론 이미 잘 만들어진 로또 정보 API들이 존재합니다. 하지만 직접 만들어보면 다음과 같은 장점이 있습니다.

-   **학습 목적**: Node.js와 Express의 동작 원리를 직접 코딩하며 이해할 수 있습니다.
-   **데이터 커스터마이징**: 원하는 형태로 데이터를 가공하여 나만의 서비스에 최적화된 응답을 만들 수 있습니다.
-   **외부 API 연동 경험**: 다른 서비스의 API를 호출하고 응답을 처리하는 실전 경험을 쌓을 수 있습니다.

이 글에서는 동행복권 웹사이트에서 비공식적으로 제공하는 데이터 조회 URL을 활용하여 최신 당첨 번호를 가져올 것입니다.

## 1단계: 프로젝트 준비

먼저 프로젝트를 시작할 폴더를 만들고, 필요한 패키지를 설치합니다.

```bash
# 1. 프로젝트 폴더를 만들고 이동합니다.
mkdir lotto-api
cd lotto-api

# 2. npm으로 프로젝트를 초기화합니다.
npm init -y

# 3. express와 axios를 설치합니다.
# express: 웹 서버를 만들기 위한 프레임워크
# axios: 외부 API에 HTTP 요청을 보내기 위한 라이브러리
npm install express axios
```

설치가 완료되면 `package.json` 파일과 `node_modules` 폴더가 생성됩니다.

## 2단계: 기본 Express 서버 만들기

이제 API 서버의 뼈대를 만들어 보겠습니다. 프로젝트 폴더에 `index.js` 파일을 생성하고 다음 코드를 작성하세요.

```javascript
// index.js

const express = require('express');
const app = express();
const PORT = 3000;

// 기본 GET 라우트
app.get('/', (req, res) => {
  res.send('로또 API 서버에 오신 것을 환영합니다!');
});

// 서버 실행
app.listen(PORT, () => {
  console.log(`서버가 http://localhost:${PORT} 에서 실행 중입니다.`);
});
```

터미널에서 `node index.js` 명령어로 서버를 실행한 뒤, 웹 브라우저에서 `http://localhost:3000`으로 접속했을 때 환영 메시지가 보이면 성공입니다.

## 3단계: 로또 번호 조회 API 엔드포인트 구현

이제 가장 중요한 로또 번호 조회 기능을 만들어 봅시다. `/:round` 파라미터를 통해 원하는 회차를 동적으로 입력받는 API 엔드포인트를 추가합니다.

`index.js` 파일에 다음 코드를 추가하세요.

```javascript
// index.js (기존 코드 아래에 추가)
const axios = require('axios');

// GET /api/lotto/:round
// :round는 조회하고 싶은 회차를 의미합니다.
app.get('/api/lotto/:round', async (req, res) => {
  try {
    const round = req.params.round;
    const url = `https://www.dhlottery.co.kr/common.do?method=getLottoNumber&drwNo=${round}`;

    // axios를 사용해 동행복권 API에 데이터를 요청합니다.
    const response = await axios.get(url);
    const data = response.data;

    // 동행복권 API 응답 결과가 실패일 경우
    if (data.returnValue === 'fail') {
      return res.status(404).json({
        ok: false,
        message: '유효하지 않은 회차입니다.',
      });
    }

    // 필요한 데이터만 추출하여 새로운 객체로 만듭니다.
    const lottoResult = {
      ok: true,
      round: data.drwNo,
      date: data.drwNoDate,
      numbers: [
        data.drwtNo1,
        data.drwtNo2,
        data.drwtNo3,
        data.drwtNo4,
        data.drwtNo5,
        data.drwtNo6,
      ],
      bonus: data.bnusNo,
    };

    // 클라이언트에게 JSON 형태로 응답합니다.
    res.json(lottoResult);

  } catch (error) {
    // 에러가 발생했을 경우
    console.error(error);
    res.status(500).json({
      ok: false,
      message: '서버 내부에서 오류가 발생했습니다.',
    });
  }
});
```

### 코드 설명

1.  `async/await`를 사용하여 비동기 HTTP 요청을 동기 코드처럼 처리합니다.
2.  `req.params.round`로 URL의 회차 번호를 가져옵니다.
3.  `axios.get()`으로 동행복권 데이터 URL에 요청을 보냅니다.
4.  응답 데이터의 `returnValue`가 `fail`이면, 유효하지 않은 회차이므로 404 에러를 응답합니다.
5.  성공 시, 원본 데이터(`drwNo`, `drwtNo1` 등)를 더 사용하기 쉬운 형태(`round`, `numbers` 배열 등)로 가공합니다.
6.  `res.json()`을 통해 가공된 데이터를 클라이언트에 전달합니다.
7.  `try...catch` 구문으로 네트워크 오류나 기타 예외 상황을 처리하여 서버가 죽지 않도록 방지합니다.

## 4단계: 전체 코드 및 테스트

수정한 `index.js`의 전체 코드는 다음과 같습니다.

```javascript
// index.js

const express = require('express');
const axios = require('axios');
const app = express();
const PORT = 3000;

app.get('/', (req, res) => {
  res.send('로또 API 서버에 오신 것을 환영합니다!');
});

// GET /api/lotto/:round
app.get('/api/lotto/:round', async (req, res) => {
  try {
    const round = req.params.round;
    const url = `https://www.dhlottery.co.kr/common.do?method=getLottoNumber&drwNo=${round}`;

    const response = await axios.get(url);
    const data = response.data;

    if (data.returnValue === 'fail') {
      return res.status(404).json({
        ok: false,
        message: '유효하지 않은 회차입니다.',
      });
    }

    const lottoResult = {
      ok: true,
      round: data.drwNo,
      date: data.drwNoDate,
      numbers: [
        data.drwtNo1,
        data.drwtNo2,
        data.drwtNo3,
        data.drwtNo4,
        data.drwtNo5,
        data.drwtNo6,
      ],
      bonus: data.bnusNo,
    };

    res.json(lottoResult);

  } catch (error) {
    console.error(error);
    res.status(500).json({
      ok: false,
      message: '서버 내부에서 오류가 발생했습니다.',
    });
  }
});

app.listen(PORT, () => {
  console.log(`서버가 http://localhost:${PORT} 에서 실행 중입니다.`);
});
```

서버를 다시 실행(`node index.js`)하고 웹 브라우저나 Postman 같은 API 테스트 도구로 아래 주소에 접속해보세요.

-   **성공 예시**: `http://localhost:3000/api/lotto/1000`
-   **실패 예시**: `http://localhost:3000/api/lotto/9999`

성공 시 다음과 같은 깔끔한 JSON 결과를, 실패 시에는 404 에러 메시지를 확인할 수 있을 것입니다.

```json
{
  "ok": true,
  "round": 1000,
  "date": "2022-02-05",
  "numbers": [2, 15, 21, 28, 35, 44],
  "bonus": 14
}
```

## 마무리

축하합니다! 이제 여러분은 자신만의 로또 당첨 번호 조회 API를 갖게 되었습니다. 여기서 더 나아가 다음과 같은 기능들을 추가해볼 수도 있습니다.

-   **캐싱(Caching)**: 한 번 조회한 결과를 잠시 저장해두어 반복적인 요청에 더 빠르게 응답하고 외부 API 호출을 줄일 수 있습니다.
-   **데이터베이스 연동**: 역대 당첨 번호를 모두 DB에 저장하여 통계 분석 기능을 만들어볼 수 있습니다.
-   **프론트엔드 구현**: 이 API를 활용하여 직접 로또 번호 조회 웹사이트나 앱을 만들어볼 수 있습니다.

이번 프로젝트가 Node.js와 Express에 더 친숙해지는 계기가 되었기를 바랍니다.
